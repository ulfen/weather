# Weather App

This is a learning project.

Technology:
- plain HTML
- CSS
- vanilla JavaScript
- Open-Meteo

Rules:
- no frameworks unless explicitly requested
- keep dependencies to a minimum
- prefer simple solutions
- don't rewrite working code unnecessarily
- explain significant architectural decisions
- test meaningful changes
- don't hide errors
- preserve existing behavior unless the task requires changing it

## Project Structure & File Scope
- Source files: `index.html`, `style.css`, `app.js`
- Generated files: `weather.html` is generated by `export.py` — do not edit directly
- When exploring the repo, ignore generated files, build outputs, and `.git`
